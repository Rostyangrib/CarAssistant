1. Цель текущего этапа

Сейчас НЕ нужно создавать голосового ассистента. Нужно реализовать полностью рабочую текстовую версию AI-ассистента, которая запускается на обычном ноутбуке. Характеристики ноутбука: • 16 GB RAM; • Windows  • Python; • локальное выполнение; • интернет желательно не использовать для основных функций. Голосовой ввод, микрофон, Wake Word и TTS на этом этапе запрещены. Пользователь взаимодействует с ассистентом только через терминал: User → текст  Assistant → текст

**16. LLM**  
Нужно предусмотреть интерфейс:  
class LLM(ABC):  
def chat(...)  
Конкретная локальная модель должна быть заменяемой.  
В первую очередь ориентироваться на модели, которые реально можно запускать на ноутбуке с 16 GB RAM.  
Не выбирать огромную модель.  
Основные требования к LLM:  

1. понимать русский язык;
2. понимать простые команды;
3. уметь выбирать tools;
4. возвращать короткие ответы;
5. работать локально.

Если для запуска конкретной модели требуется дополнительное ПО, например Ollama или llama.cpp, это допустимо.  
Но приложение не должно быть жёстко связано с одной конкретной моделью.  

⸻  

**17. LLM system prompt**  
Создать отдельный system prompt.  
Он должен объяснять модели:  
Ты — локальный автомобильный AI-ассистент.  

Ты отвечаешь пользователю на русском языке.  

Ты можешь:  

- разговаривать;  
- управлять музыкой через предоставленные tools.

Если пользователь просит выполнить действие с музыкой, используй соответствующий tool.  

Не выдумывай результаты tool.  

Не утверждай, что музыка включена, если tool вернул ошибку.  

Ответы должны быть короткими.  
System prompt хранить отдельно от Python-кода.
